# Calculadora - Jaime Pujol

Enlace a la web: https://jaimepujolca-hash.github.io/

Práctica de la calculadora web. Lo que he hecho:

- He añadido un campo de información que te dice si el resultado es menor que 100, está entre 100 y 200 o es mayor que 200.
- Botones de valor absoluto (|x|) y factorial (x!).
- Suma y multiplicación: metes un número, pulsas + o x, metes el otro y le das a =.
- Botones para listas separadas por comas: sumar, ordenar, invertir y quitar el último.
- Si dejas el campo vacío o pones algo que no es un número, sale un mensaje de error.
